LAYER 2 — FASTAPI BACKEND (backend/)
API Endpoints
api/main.py
POST /api/classify
validates content, calls predictor, stores in session
GET /api/feed/next
gets batch from FeedSimulator, classifies each post
GET /api/stats
emotion counts, topic counts, alert logic
Alert rule: negative+angry > 40% of last 30 posts
GET /health
cold start wake, returns model info
Session state: in-memory list (no database)
Prediction Engine
api/predictor.py
Tier 1
≤3 words: neutral, confidence 0.4, £0 cost
Tier 2
4–20 words: Claude Haiku
emotion + topics, no SHAP
Tier 3
>20 words: TF-IDF → XGBoost → SHAP top 5 words
Topic model: multi-label, threshold 0.3, returns top 2
Both models share single TF-IDF vectoriser
Model Artefacts
backend/model/
Emotion Model
emotion_model.pkl: XGBoost multiclass
5 classes: excited, positive, neutral, negative, angry
Topic Model
topic_model.pkl: XGBoost OneVsRest multi-label
6 topics: winner_reaction, presenter_performance,
ceremony_production, diversity_representation,
fashion_red_carpet, general_audience_reaction
Shared Vectoriser
vectorizer.pkl: TF-IDF shared by both models
mlb.pkl: MultiLabelBinarizer

Scripted BAFTA Arc (feed.py) — 30 posts across 5 stages designed to produce a measurable narrative arc for demo purposes:
Opening (excited) → Early Awards (positive) → Controversy (negative/angry spike) → Recovery (excited) → Closing (positive)
